# Tycoon Empire

A single-file idle tycoon game inspired by classic capitalist clicker/idle empire games.

## Play locally

Open `index.html` in any modern web browser.

## Publish with GitHub Pages

1. Go to **Settings → Pages**.
2. Under **Build and deployment**, set the source to **Deploy from a branch**.
3. Choose the `main` branch and `/root`, then save.
4. Your game will be available at:
   `https://dkruse-rgb.github.io/tycoon-empire/`

## Files

- `index.html` — the playable game.
- `.nojekyll` — prevents GitHub Pages from processing the project with Jekyll.
